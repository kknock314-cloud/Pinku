# Universal Ad-Free Player
A basic Android application for playing web videos with Picture-in-Picture (PiP) support via WebView.

## Features
* **Custom URL Input:** Play any video link.
* **Picture-in-Picture:** Floating window support (Android 8.0+).
* **Background Playback:** Continues playing when switching apps.
* **Orientation Support:** Adapts to landscape and portrait seamlessly.
